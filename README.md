This repository contains a double pendulum project with more code than you ever asked for. 
It simulates a double pendulum with pymunk and draws some basic sprites using pygame.

#Pymunk demo.py 
This file contains the main loop, where everything is initialized
#PhysicsObject.py
This file contains all classes that handle the drawing of physics objects. The
Physicsmanager can handle the drawing of all physics objects in the objects_list
sequentially. Not more not less.
#Button.py
This file contains a very basic prototype of a button, unfortunately the logic for the
button is still done in the main loop. Pygame handles the button logic.
#legacy
Old files that you wouldnt neccesarily want to throw away.
